# Referências

Modelos originais que o código reproduz. Não entram no bundle: servem para
conferir, ao mexer no gerador, se o resultado continua igual ao documento
oficial.

- `etiqueta_example.xlsx` — formulário PR-5290.00-22000-970-ST5-502
  (FORM-PADRAO.Rev00), a etiqueta de preservação. Layout, textos fixos, cores e
  proporções não podem ser alterados; o gerador é `src/lib/etiquetasLotes.ts`.
